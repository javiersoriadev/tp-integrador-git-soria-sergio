# Proyecto Integrador - Git y GitHub

## Descripción
Repositorio desarrollado para el Trabajo Práctico Integrador del curso de Git y GitHub del Nodo Tecnológico. Consiste en una estructura web básica y la documentación completa del proceso de control de versiones.

## Objetivo
Aplicar de manera integrada los conceptos y comandos fundamentales de Git y GitHub mediante la creación, versionado, publicación y documentación de un proyecto digital.

## Estructura del repositorio
- `README.md`: Documentación general y explicación del proyecto.
- `ENTREGA.md`: Registro del proceso de trabajo, comandos utilizados y dificultades.
- `proyecto/`: Carpeta contenedora del archivo principal de la landing (`index.html`).
